远程交付需要守住哪些边界

边界 实现要求
身份 错误 token 拒绝；配对独立且限时
事件 未鉴权无事件；会话按 owner 授权
请求 requestId 幂等；超时先查状态
恢复 保存绑定、事件与快照；发现重放缺口
文件 绑定 endpoint；限制根目录并检查真实路径
产物 远端生成后通过下载通道保存本机

当前 bridge 会向错误 token 连接返回凭证。 它还会向所有已打开连接广播事件。 这些行为必须修复，再交付远程功能。
