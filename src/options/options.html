Vela 设置

模型供应商（API Key）

在这里统一配置 API Key：LLM 问答 / LLM 任务聊天、网页总结、整页翻译、划词翻译 / 解释共用这些供应商。支持任意兼容 OpenAI 或 Anthropic 协议的服务，Base URL 填到版本根（如 https://api.openai.com/v1、https://api.anthropic.com、Ollama 填 http://localhost:11434/v1），保存时会自动归一。勾「默认」的供应商用于翻译、总结与划词；聊天在顶栏模型下拉里可按对话选任一供应商的模型。只用 Agent 引擎聊天时可以不配。

全局参数

部分新模型（如 OpenAI o 系 / GPT-5 系）不接受 temperature 或 max_tokens，留空最稳。

聊天引擎

聊天顶栏可按对话切换引擎，切换后作为新对话默认值记住。LLM 问答 / LLM 任务直接调用上方「模型供应商」里配置的 API Key，无需 bridge。任务模式下模型可读取当前网页、选中内容、标签页与网址正文；打开网页、联网读取、下载文件等操作会先弹卡确认。

本地 Agent（聊天）

○ 未连接

每个对话自动在基础目录下建独立子目录（<基础目录>/<对话 id>）作为 agent 工作区，知识库与附件也存放在该子目录内。支持 ~。权限模式是 agent 工具调用的审批策略：每步审批对每个工具弹卡等待允许；自动接受编辑放行文件编辑、其余仍审批；自动放行不再弹卡（agent 可直接执行任意命令，仅限可信环境）。聊天页输入框下方可按会话覆盖权限模式与模型。先启动 bridge：cd bridge && npm i && node index.js；token 无需手动设置——扩展与 bridge 首次握手自动配对。检测列出本机已装的 agent 及登录态；未登录时按提示的命令先完成登录。只用 Agent 引擎聊天时，无需配置上方的模型供应商。

网页翻译

翻译使用上方「默认」供应商。翻译的模型 / 语言 / 模式也可将鼠标悬停在页面浮窗的「翻译此页」按钮上就地切换。

高级参数

翻译按视口滚动逐步进行，这里限制单页累计翻译总量；批次越小回填越快，越大越省请求。

选中快捷动作（右键菜单）

prompt 模板中的 {text} 会替换为选中文本（截前 2000 字符）。保存后右键菜单自动刷新。
